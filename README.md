# Sigil

> **Sigil** — маленький язык программирования с сигилами и своей цветовой системой.

Файлы программ имеют расширение `.sg`. Интерпретатор — один файл на Python, без зависимостей.

```
%a = 3
@%a > 0:
	>: %a
	%a = %a - 1
```

## Запуск

Нужен Python 3.9+.

```
python sigil.py main.sg
```

Тесты:

```
python -m unittest discover -s tests -v
```

## Синтаксис за минуту

| Символ | Значение | Пример |
|---|---|---|
| `%` | переменная | `%ac = 1` |
| `#` | системный вызов | `#date`, `#rnd(1, 10)` |
| `$` | пользовательская функция | `$sum(%a, %b):` |
| `:<` | вернуть значение из функции | `:< %a + %b` |
| `>:` | вывод в консоль | `>: %ac` |
| `<:` | ввод пользователя | `%ac = <:` |
| `?` | если | `? %x > %y:` |
| `> ?` | иначе если | `> ? %x == %y:` |
| `>` | иначе (на новой строке, без `:`) | |
| `@` | цикл, пока условие истинно | `@%a > %b:` |
| `!` `&` `\|` | не, и, или | `? %a > 1 & !(%b == 3):` |
| `'...'` | строка | `'кусок'` |
| `[ ]` | список, индекс с нуля | `%l = [1, 2]`, `%l[0]`, `%l[1] = 5` |
| `~` `!~` | входит / не входит (подстрока или элемент списка) | `? %m ~ 'rps':` |
| `;` | комментарий до конца строки | `; 'текст'` |

Блоки задаются отступом: таб или четыре пробела.

Текст и число при сложении превращаются в текст: `'кусок ' + 5` даёт `'кусок 5'`. Сравнение со строкой работает так же: `'10' < 9` сравнивает `"10"` и `"9"`. Внутри кавычек ничто не обрабатывается: `'%a $x #rnd'` — просто текст.

Полное описание — в [sigil.md](sigil.md).

### Случайные значения

| Вызов | Результат |
|---|---|
| `#rnd` | целое от 0 до 100 |
| `#rnd(1, 10)` | целое в диапазоне |
| `#rnd('abc')` | случайный символ |
| `#rnd(5, 'abc')` | строка длины 5 из алфавита |

Остальное: `#date` — сегодняшняя дата, `#len(x)` — длина текста или число элементов списка, `#lower(x)` и `#upper(x)` — текст в нижнем или верхнем регистре, `#num(x)` — текст в число (на нечисловом тексте ошибка с названием текста), `#add(список, значение)` — новый список с добавленным элементом, `#join(список, разделитель)` — список в текст, `#split(текст, разделитель)` — текст в список (пустой разделитель режет на символы).

### Списки

```
%nums = [5, 3, 8]
%nums[0] = 1                 ; изменить элемент (индекс с нуля)
%nums = #add(%nums, 4)       ; добавить: возвращает НОВЫЙ список
>: %nums                     ; [1, 3, 8, 4]
>: #len(%nums)               ; 4
>: 3 ~ %nums                 ; True: ~ ищет элемент
%copy = %nums                ; это копия, а не ссылка
```

Пример с сортировкой — [list_example.sg](list_example.sg).

`~` проверяет подстроку, и пустая строка слева никогда не «входит»: `'' ~ 'rps'` ложно. Чтобы проверить ровно один символ из набора, пишите `#len(%m) == 1 & %m ~ 'rps'`.

## Пример: калькулятор

```
>: 'First number:'
%a = <:
>: 'Operation (+, -, *, /):'
%op = <:
>: 'Second number:'
%b = <:

? %op == '+':
    >: %a + %b
> ? %op == '/':
    ? %b == 0:
        >: 'Error: division by zero'
    >
        >: %a / %b
>
    >: 'Error: unknown operation'
```

## HUSTL: цвет в консоли

Цветной вывод — `>:КООРДИНАТА 'текст'`:

```
>:E2 'Цвет палитры консоли'
>:E2.210 'Более тёмный вариант'
```

Координата PFF (PrismField Format) записывается так:

- **буква A–Z** — крупный сектор оттенка;
- **цифра 0–9** — крупная ячейка насыщенности;
- **цифры после точки** уточняют координату по очереди: оттенок, насыщенность, светлота, затем цикл повторяется. Суффикс может быть любой длины.

Без суффикса берётся середина ячейки и средняя светлота. В терминале цвет округляется до ближайшего из 256-цветной палитры.

Название HUSTL — случайное. Совпадение с Hue / Saturation / Lightness удачное, но намеренным не было.

## Подсветка в VS Code

В [editors/vscode-sigil](editors/vscode-sigil) лежит расширение: подсветка `.sg`, автозакрытие кавычек и скобок, автоотступ после строк, заканчивающихся на `:`. Установка — скопировать папку в каталог расширений и перезапустить VS Code:

```powershell
Copy-Item -Recurse editors\vscode-sigil "$env:USERPROFILE\.vscode\extensions\sigil-0.1.0"
```

## Ограничения

- Нет операторов `%`, `//`, `**`.
- Типы: числа, строки, даты и списки. Словарей нет.
- Списки — значения, а не ссылки: присваивание копирует, `#add` возвращает новый список, отрицательных индексов нет.
- Глубина рекурсии ограничена Python; цикл — миллионом итераций.
