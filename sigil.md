% - переменная, напр %ac = 1
# - системный вызов, например #date. #rnd без аргументов выдаёт целое число от 0 до 100; #rnd(1, 10) — целое число в диапазоне; #rnd('abc') — случайный символ; #rnd(5, 'abc') — строку длиной 5 из указанного алфавита.
$ - пользовательская функция, например $sum(%a, %b):
:< - возврат значения из функции, например :< %a + %b
HUSTL - цветовая система Sigil. PFF (PrismField Format) - формат записи координат цвета, например E2.210.
? - if, > (с новой строки, без :) - else
: - символ продолжения (закончилось условие и т.д.)
>: - вывод в консоль, например >: %ac
>:COLOR - цветной вывод, например >:E2 'Текст'. В PFF буква A-Z задаёт крупный сектор оттенка, цифра 0-9 — крупную ячейку насыщенности. Без суффикса берётся середина ячейки и средняя светлота. Цифры после точки уточняют координату по очереди: оттенок, насыщенность, светлота, затем повтор цикла. Суффикс может быть любой длины. Для консоли цвет преобразуется в ближайший оттенок 256-цветной палитры терминала.
<: - пользовательский ввод, например %ac = <:
+-*/ - арифметические операторы, разделение точкой 2 + 0.22
'' - кавычки для строковых значений, например 'кусок', при сложении текста с цифрами преобразование в сторону текста, например 'кусок ' + 5 = 'кусок 5'
! - не, & - и, | - или, например ? %a > 1 & !(%b == 3) | %c: . Приоритет ниже сравнений (как and/or/not в Python), != по-прежнему «не равно». Внутри кавычек символы %, #, $, !, &, | и слова true/false не обрабатываются.
Сравнение, как и +, приводит число к тексту, если с одной стороны строка: '10' < 9 сравнивает "10" и "9".
~ - «входит в»: 'r' ~ 'rps' истинно, ~ проверяет подстроку, оба значения приводятся к тексту. !~ - «не входит». Пустая строка слева никогда не «входит» ('' ~ 'rps' ложно, '' !~ 'rps' истинно). Приоритет как у сравнений. Чтобы проверить ровно один символ из набора: #len(%m) == 1 & %m ~ 'rps'.
[ ] - список, например %l = [1, 'два', 3]; %l[0] - элемент по индексу (с нуля), %l[1] = 'х' - присвоить элемент, [] - пустой список. Индекс - целое от 0 до длины-1, иначе ошибка (отрицательные индексы не поддерживаются). Вложенные списки: %m[1][0]. Текст тоже можно индексировать ('abc'[1] — 'b'), но менять нельзя.
Списки - значения, а не ссылки: %b = %l делает копию, параметры функций копируются, функция не меняет внешний список. Поэтому #add возвращает новый список: %l = #add(%l, 4). Строка #add(%l, 4) сама по себе - ошибка.
#add(список, значение) - новый список с добавленным в конец значением.
#join(список, разделитель) - склеивает элементы списка в текст через разделитель, элементы как обычный текст (без кавычек): #join([1, 'a'], ', ') — '1, a'.
#split(текст, разделитель) - режет текст на список строк: #split('a,b', ',') — ['a', 'b']. Пустые куски сохраняются ('a,,b' даёт три элемента, '' даёт ['']). Пустой разделитель режет на символы: #split('abc', '') — ['a', 'b', 'c']. Элементы всегда текст, не числа. В #join и #split разделитель обязателен.
+ для списков склеивает ([1] + [2]), * повторяет ([0] * 3), результат не больше 1 000 000 элементов. ~ для списка проверяет элемент ('b' ~ ['a', 'b']), а не подстроку; число и текст сравниваются как в ==.
#len(x) - длина значения: для списка число элементов, иначе длина текста, например #len('abc') — 3.
#num(x) - текст в число: #num('42') — 42, #num(' 2.5 ') — 2.5. Принимаются ровно те записи, которые <: распознаёт как число: целые и дробные с точкой, со знаком + или -, пробелы по краям игнорируются, цифры только 0-9; запись с запятой, экспонентой (1e5), пустая строка и любой другой текст — ошибка (#num cannot convert 'abc' to a number). Число возвращается как есть. Список, дата и true/false — ошибка.
#isnum(x) - истина, если значение число или текст, который #num примет (#isnum('2.5') истинно, #isnum('1,5') и #isnum('abc') ложно). Ошибок не даёт ни на каком значении: для списка, даты и true/false просто ложь. Нужен, чтобы переспрашивать ввод: @!#isnum(%n): (см. sum_example.sg).
#lower(x), #upper(x) - значение как текст в нижнем / верхнем регистре, например #lower('ПриВет') — 'привет'. Работают и с кириллицей.
; - комментарий, не исполняемый код: всё от ; до конца строки, например ; 'текст'. Можно отдельной строкой (отступ не важен) и после кода. Кавычки в комментарии необязательны. Внутри строки в кавычках ; — обычный символ.
@ - цикл пока условие истинно, например @%a > %b:
@%x : список_или_текст: - цикл по элементам списка (или по символам текста), например @%c : 'abc': или @%n : [4, 9, 2]:. Переменная %x получает каждый элемент по очереди и остаётся после цикла со значением последнего (если элементов не было - не меняется). Цикл идёт по копии: изменение списка внутри цикла на ход цикла не влияет, как и изменение %x не меняет сам список. Обход числа, даты и true/false - ошибка. Заголовок вида @%x : : (пустая правая часть) - ошибка, а @%x: с одним двоеточием - обычный цикл пока по переменной %x.

Примеры
? %x > %y:
	%a = %x
>
	%a = %y

%a = 3
%b = 0
@%a > %b:
	>: %a
	%a = %a - 1

%number = #rnd(1, 10)
%letter = #rnd('abcdefghijklmnopqrstuvwxyz')

$sum(%a, %b):
	:< %a + %b
%total = $sum(2, 3)
>: %total

>:E2 'Текст палитрой консоли'
>:E2.210 'Более тёмный вариант'

? %x > %y:
	%a = %x
> ? %x == %y:
	%a = %x + %y
>
	%a = %y
